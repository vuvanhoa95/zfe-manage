# Plan: Phase 2 - Smart Input Features
Created: 2026-02-03
Status: 🟡 In Progress

## Overview
Phase 2 focuses on accelerating data entry using Voice-to-Text and Business Card Scanning. We will use the Web Speech API for free transcriptions and OpenAI (GPT-4o-mini and GPT-4o-vision) for parsing unstructured data into structured JSON objects.

## Tech Stack
- **Voice Recognition**: Web Speech API (via `react-speech-recognition`)
- **Parsing**: OpenAI GPT-4o-mini
- **OCR/Vision**: OpenAI GPT-4o-vision
- **UI**: Tailwind CSS, Lucide React
