# Open Prisma Studio

Mở Prisma Studio để xem và quản lý database.

## Mô tả
Mở Prisma Studio - GUI tool để browse và edit database.

## Command

```bash
npx prisma studio
```

## Access
- Prisma Studio: http://localhost:5555

## Lưu ý
- Prisma Studio cho phép xem và edit data trực tiếp trong database
- Hữu ích cho development và debugging
- Không nên sử dụng trong production
- Có thể filter, sort, và edit records qua UI
