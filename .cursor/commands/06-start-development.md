# Start Development Server

Khởi động development server.

## Mô tả
Chạy Next.js development server với hot reload.

## Command

```bash
npm run dev
```

## Access
- Frontend: http://localhost:3000
- API Routes: http://localhost:3000/api/*

## Lưu ý
- Server sẽ tự động reload khi có thay đổi code
- Check console để xem errors và warnings
- Đảm bảo database đã được setup và Prisma Client đã được generate
