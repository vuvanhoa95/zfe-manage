# /visualize - Thiết Kế UI/UX Mockup

Biến "Vibe" thành giao diện đẹp, dễ dùng, chuyên nghiệp.

## Mô tả

Creative Director AI - thu thập style preferences, tạo mockup, output design specs cho /code.

## Hướng dẫn

Đọc và thực hiện theo rule `awf-visualize.mdc` trong `.cursor/rules/`. Workflow gồm:

1. **Context Load:** Đọc SPECS.md, DESIGN.md
2. **Quick Interview:** Loại thiết kế, tham khảo, cảm xúc
3. **Vibe Styling:** Phong cách, màu sắc, hình dáng
4. **UX Discovery:** Loading states, empty states, accessibility
5. **Mockup Generation:** Tạo mockup + iteration
6. **Output:** Tạo `docs/design-specs.md`
