## 🎨 Design Elements

### **Color Palette:**
```css
Primary (Navy):   #053663
Accent (Blue):    #178AF3
Graphite:         #2F343A
Text Secondary:   #5B6470
Background:       Gradient (slate-50 → blue-50 → indigo-100)
```

### **Typography:**
- Logo: 4xl, bold, italic
- Title: 2xl, bold
- Body: Base, regular
- Labels: sm, semibold

### **Spacing:**
- Card padding: 8 (32px)
- Input padding: 3.5 (14px)
- Gap between elements: 5 (20px)

### **Shadows:**
- Card: shadow-2xl
- Logo box: shadow-2xl với blue-500/30
- Button: shadow-lg với blue-500/30
